# Justype

A DOS-style typing game made with LÖVE2D. Type moving words before they reach the edge.

## Controls

- `W/S/↑/↓` — navigate
- `SPACE` — select
- `BACKSPACE` — back
- `ESC` — return to menu / quit
- `Ctrl+U` — clear input (in-game)
